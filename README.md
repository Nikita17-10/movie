"# movie" 

Movie API - Spring Boot REST API

How to Run:
1. Import project in Eclipse
2. Run MovieApiApplication
3. Server runs on port 9091

Endpoints:

POST /movies
Add movie.

GET /movies/{id}
Get movie by ID.

GET /movies
Get all movies.

Storage:
In-memory ArrayList used.

Validation:
Movie name and description are required.
